# Loan-Analysis
Loan analysis are to assess the borrower's creditworthiness and ability to repay the loan, determine the associated risks for the lender, and make an informed decision on whether to approve the loan and on what terms.

It involves using financial statement analysis,credit history,and metrics like the debt-to-income ratio to determine if a loan should be granted and what terms to offer.Loan ID is a unique identifier assigned to each loan application or loan account. It serves as a primary key for tracking and managing individual loans. 

Address State indicates the borrower's location. Employee Length provides insights into the borrower's employment stability. Longer employment durations may indicate greater job security.

Grade represents a risk classification assigned to the loan based on creditworthiness. Higher grades signify lower risk. Purpose specifies the reason for the loan (e.g., debt consolidation, education). It helps understand borrower intentions. Interest Rate represents the annual cost of borrowing expressed as a percentage. It determines the loan's cost.
